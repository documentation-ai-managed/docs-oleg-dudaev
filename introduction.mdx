## Quick Start

Get up and running with Oleg Dudaev in just a few steps.

<Steps>
  <Step title="Create Your Space" icon="plus">
    Sign up at `https://dashboard.example.com` and create a new documentation space.
  </Step>
  <Step title="Add Your First Page" icon="file-plus">
    Click "New Page" and start editing with MDX. Use the visual editor or raw MDX.
  </Step>
  <Step title="Publish and Share" icon="globe">
    Deploy instantly. Share your live docs URL with your team.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python">
```javascript
// Fetch your docs API
const response = await fetch('https://api.example.com/docs', {
  headers: {
    Authorization: `Bearer ${YOUR_API_KEY}`
  }
});
const docs = await response.json();
console.log(docs);
```
```python
import requests

response = requests.get(
  'https://api.example.com/docs',
  headers={'Authorization': f'Bearer {YOUR_API_KEY}'}
)
docs = response.json()
print(docs)
```
</CodeGroup>
