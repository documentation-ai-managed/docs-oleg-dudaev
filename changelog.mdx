## Recent Updates

Stay informed about the latest releases. You receive automatic notifications for major updates, but review this changelog for detailed changes, breaking updates, and migration steps.

<Update label="2024-08-10" description="v1.0.0" tags={["breaking", "feature"]}>

## Breaking Changes

- Updated API endpoints from `/v0/` to `/v1/` prefix. Migrate your integrations by updating base URLs to `https://api.example.com/v1/`.
- Removed deprecated `legacyAuth` parameter; use `Authorization: Bearer YOUR_TOKEN` instead.

## New Features

- Core documentation management with MDX support and component library.
- Full-text search across all project spaces.

## Initial Setup

- First stable release with project organization tools.

</Update>

## Upgrade Instructions

<Callout kind="alert">
  Always back up your documentation space before upgrading. Test in a staging environment if possible.
</Callout>

Follow these steps to upgrade Oleg Dudaev smoothly.

<Steps>
  <Step title="Backup Your Data" icon="database">
    Export your spaces using the built-in CLI tool.

    <CodeGroup tabs="CLI,Docker">
      ````bash
      oleg-dudaev export --space-id YOUR_SPACE_ID --output backup.json
      ````

      ````bash
      docker run olegdudaev/export:latest --space-id YOUR_SPACE_ID > backup.json
      ````
    </CodeGroup>
  </Step>

  <Step title="Update Package" icon="download">
    Install the latest version via your package manager.

    <Tabs>
      <Tab title="npm" icon="package">
        ````bash
        npm install oleg-dudaev@latest
        ````
      </Tab>
      <Tab title="yarn" icon="package">
        ````bash
        yarn add oleg-dudaev@latest
        ````
      </Tab>
    </Tabs>
  </Step>

  <Step title="Run Migrations" icon="settings">
    Execute database migrations for new features.

    ````bash
    oleg-dudaev migrate --api-key YOUR_API_KEY --endpoint https://api.example.com/v1/migrate
    ````
  </Step>

  <Step title="Verify Installation" icon="check-circle">
    Test core functionality with a sample API call.

    <Request tabs="cURL,JavaScript" show-lines="true">
      ````bash
      curl -X GET https://api.example.com/v1/spaces \
        -H "Authorization: Bearer YOUR_API_KEY"
      ````

      ````javascript
      const response = await fetch('https://api.example.com/v1/spaces', {
        headers: {
          'Authorization': 'Bearer YOUR_API_KEY'
        }
      });
      const spaces = await response.json();
      console.log(spaces);
      ````
    </Request>
  </Step>
</Steps>
